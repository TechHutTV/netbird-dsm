x86_64

64-bit Intel or AMD models, including DS920+, DS923+, and DS1522+.

aarch64

64-bit ARM models, including DS220j, DS223j, and DS124.

Not sure which architecture?

Run this command on your NAS over SSH:

synogetkeyvalue /etc.defaults/synoinfo.conf unique

The output is synology_<chip>_<model>. Chips such as apollolake, geminilake, v1000, r1000, and denverton use the Intel / AMD source. Chips such as armada37xx, rtd1296, and rtd1619b use ARM64. See the full architecture lists for other supported chips.

Install in Package Center

  1. Open Package Center → Settings → General and select Any publisher under Trust Level.
  2. Open Package Sources, select Add, and paste the URL for your architecture.
  3. Find NetBird in the Community tab and install it.
  4. Open NetBird from DSM's main menu to enroll and connect your NAS.

Installing an SPK directly? Follow the manual installation steps.

Uninstall the package

Stop NetBird before uninstalling to avoid leaving the package in a stuck state.

  1. In Package Center, open NetBird → Action → Stop, or run sudo synopkg stop netbird over SSH.
  2. Select Action → Uninstall.

Back up package state before uninstalling if you need to retain enrollment.
